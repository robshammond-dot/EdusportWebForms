How our enquiry forms work

There are five enquiry forms on the Edusport website. Each one is built for a specific job, asks specific questions, and sends its information to a specific place. This guide explains what each form does and why.

Check this guide first whenever an enquiry looks different to what you expected.

Why the forms are different

The more the website already knows about what the client is looking at, the fewer questions the form needs to ask. A client on a package page doesn't need to tell us the package or the dates, because the page already knows. A client using the General form could be interested in anything, so that form has to ask.

04Event Page form

On each event page · sends to Freshsales only

Same questions as the General form, with two differences that save the client time:

  • Sport and event are preselected based on the event page the client is on.
  • The event dates are sent to Fresh automatically. The client still tells us their own departure and return dates, so you get both: when the event is on, and when they want to travel.

05Package Enquiry form

On package pages · all packages except RWC · sends to Freshsales only

This form is an enquiry form only. It does not create a quote. The client doesn't see a sport or event question, because the page already knows the package. These come through to Fresh as hidden fields:

Package datesPulled from the package, no need for the client to select them.
Package name & URLSo you can see exactly which package the client was looking at.
Sport type & eventSent as hidden, associated fields.

The client then answers: departure and return dates in mind, number of travellers, flights, further requests, travelled with us before, travel agent, and marketing preference.

06RWC 2027 Quote Me form

RWC 2027 packages only · sends to Freshsales and UDMS

This form is tagged only to RWC 2027 packages

Every other package uses the Package Enquiry form. The Quote Me form works differently because it creates and sends a quote in UDMS before the enquiry reaches Fresh.

What happens after the client clicks submit

  1. 1
    The package is set up as a quoted packageThe RWC package has a tick box in the website CMS that marks it as a quoted package. This is what switches the Quote Me form on.
  2. 2
    The client chooses rooms and guestsThe form asks how many rooms and how many people in each room, Single or Double.
  3. 3
    Zapier maps the answersThe form fields are sent to the right fields in UDMS and Freshsales.
  4. 4
    UDMS tries to build the quoteUDMS reads the traveller and room details and creates the quote. An ED number is generated either way.
  5. 5
    Then, and only then, the enquiry lands in FreshFresh waits for UDMS to respond, so the enquiry arrives with the right status and the ED number already in the ED Reference field.

The two possible outcomes

A · Quote sent

  • UDMS sends the quote to the client
  • The enquiry goes into the Quoted lifecycle in Fresh
  • It is auto-assigned to a consultant
  • ED Reference is filled in
  • Your job: follow up on the quote the client already has

B · No quote sent

  • UDMS couldn't create the quote
  • The enquiry goes into a separate lifecycle in Fresh for unquoted RWC enquiries
  • It is still auto-assigned to a consultant
  • ED Reference is still filled in
  • Your job: pick it up and handle the quote manually
RWC Quote Me enquiries do not appear as New

Either outcome lands the enquiry straight in its own lifecycle, already assigned. If you're looking for one in New, you won't find it there.

07Waitlist form

Sends to Freshsales · lands straight in Waitlist

The Waitlist form is not a request for a quote. It holds the client's place in line for an event until spaces open up.

Shares: event nameSo you know which event the client is waiting on.
Shares: travellersThe number of people in the client's party.
Does not share: datesNo travel or event dates come through. That's by design.
Waitlist enquiries do not appear as New

They go straight into Waitlist in Fresh and stay there until the waitlist clears. If you're looking for one in New, you won't find it there.

10Quick answers

The questions that come up most

Why does the General form ask for dates and flights?

Because it isn't linked to an event or a package. Those qualifying questions are the only way we get the information needed to quote.

Why doesn't the Package Enquiry form ask which package or event?

It doesn't need to. The package name, URL, dates, sport type and event all come through to Fresh automatically as hidden fields.

Why are the Yes / No answers blank when the form loads?

So the client has to make a real choice. A pre-ticked default would land in Fresh looking like an answer the client never gave.

Can the Quote Me form be added to other packages?

No. It is tagged only to RWC 2027 packages. All other packages use the Package Enquiry form, which sends to Fresh only and doesn't create a UDMS quote.

I can't find an RWC Quote Me enquiry in New. Where is it?

It won't be in New. If UDMS sent the quote, it's in the Quoted lifecycle. If not, it's in the separate lifecycle for unquoted RWC enquiries. Either way it is already assigned to a consultant.

Why does an RWC enquiry take a moment longer to appear in Fresh?

Fresh waits for UDMS to respond first. That way the enquiry arrives in the right lifecycle with the ED Reference already filled in.

Where do I find the UDMS ED number for an RWC enquiry?

In the ED Reference field on the enquiry in Fresh. It is filled in whether or not the quote was sent.

Why doesn't a Waitlist enquiry have any dates?

The Waitlist form doesn't share dates. It only sends the event name and the number of travellers, because the client is waiting for space, not asking for a quote yet.

I can't find a Waitlist enquiry in New. Where is it?

It goes straight to Waitlist and stays there until the waitlist clears.

Can we add, remove or rename a question on a form?

Every question is mapped to a field in Fresh (and for RWC, in UDMS) through Zapier. Changing a question changes what lands in Fresh, so any change has to be planned across all of these, not just on the website.
